# Khmer Hunspell Dictionary Files

This directory should contain the Khmer Hunspell dictionary files for spell checking:

- `km_KH.dic` - The dictionary file containing Khmer words
- `km_KH.aff` - The affix file containing rules for word formation

## How to obtain

These files should be your custom Khmer Hunspell dictionary files created for spell checking.

## Usage

The spell checker will automatically load these files when the editor initializes.
If the files are not found, the spell checker will log a warning and continue without spell checking.
